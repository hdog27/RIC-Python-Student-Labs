# Fictional test fixtures

`sample-tasks.json` is valid and intentionally uses non-contiguous IDs 1 and 7.
`malformed.json` is deliberately truncated JSON.
`wrong-schema.json` parses but contains an invalid done value.

Copy fixtures into a scratch folder for experiments. Preserve master copies. Do not replace personal save files with these fixtures. The app rejects the invalid files without overwriting them.
