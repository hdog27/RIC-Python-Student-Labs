# Python Student Labs: TaskTrack

Build a command-line task tracker in five days. Start with Python fundamentals, then create an application that can add tasks, list them, mark them complete, and save them between runs. Finish with tests, a user guide, and a short demonstration you can include in a portfolio.

For rising high school juniors and seniors. No previous programming required. Each day includes **180 minutes of guided learning and 180 minutes of project work**. Breaks and lunch are additional.

## Your week

| Day | Learn | Build and submit |
| --- | --- | --- |
| Monday | Variables, strings, input, conversion, decisions | A working task-entry prototype and project proposal |
| Tuesday | Lists, dictionaries, loops, functions | In-memory add/list/complete operations |
| Wednesday | Modules, JSON, paths, exceptions | Save/load and recovery from invalid data |
| Thursday | Debugging, unit tests, integration | An integrated app and test evidence |
| Friday | Peer review, documentation, presentation | A reproducible project and three-minute demo |

## Working files

Download **Code > Download ZIP**, extract it, and follow setup. A GitHub account is optional. Work on a copy of `05 - Final Project/starter`, leaving your downloaded master copy unchanged. Use Python 3.11 or later. No pip packages, API keys, paid services, or cloud accounts are needed for the core course.

The starter intentionally contains incomplete functions. Its acceptance tests describe the target and will fail until you implement it. The tiny examples in `04 - Activities & Labs/demos` are runnable teaching examples.

## Instructor materials

Teaching plans, answer keys, assessment scoring, and the completed application belong in a separate **private repository**. They are excluded from this student repository, its slide notes, and its history. Instructors should request access from the project owner. Student and instructor repositories have independent histories.

Use fictional task titles in shared screenshots. Keep real names, private schedules, passwords, and personal data out of public submissions. See the project packet for the AI assistance and attribution policy.
