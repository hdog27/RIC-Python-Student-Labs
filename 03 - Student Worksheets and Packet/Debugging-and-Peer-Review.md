## Clean-copy review

Reviewer: __________  Project version or snapshot: __________

1. Follow the README in a new writable folder, without coaching from the author.
2. Record interpreter version and exact launch command.
3. Run tests and the manual project checklist. Preserve the output.
4. Report one concrete strength and one reproducible issue. Include the input and expected behavior.
5. The author records the repair or explains a documented limitation.

Feedback should describe behavior rather than the person. Each student must explain one function and one test independently, even on team projects.
