# Post-assessment

15 minutes, individual, no notes or AI. Use the same anonymous classroom ID as the pre-assessment. Total: 20 points, two per question.

1. Predict `print("4" + "6")`. Explain the value's type.
2. Explain the difference between `total = 9` and `total == 9`.
3. A user types `12` at an input prompt. Give a conversion that permits numeric addition. What happens if the user types `twelve` instead?
4. Predict the output of `for n in [2, 5]: print(n * 3)` in order.
5. Given `{"id": 12, "title": "Practice", "done": True}`, show how to read the title field.
6. Explain the caller's result when a function uses print but omits return. Why does that matter for tests?
7. Describe a save/load sequence that preserves a new task after restarting an app.
8. Tasks have IDs 2 and 12. Why is `tasks[12]` the wrong way to find the task with ID 12?
9. JSON parses successfully but contains duplicate IDs and done values of "yes". What should loading do, and what should happen to the original file?
10. Propose a test for an invalid title or unknown ID. Include setup, action, and expected result.

Confidence, 1–5: writing code ___ reading errors ___ explaining code ___
